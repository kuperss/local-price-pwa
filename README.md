## 開始測試新版

1. 手機用一般瀏覽模式開前端，填姓名申請；不要用無痕模式做離線測試。
2. 電腦開後台完成管理員驗證，在「裝置與使用者」開通剛才的手機。
3. 手機按「重新確認」，等料檔載入，核對更新時間、產品筆數及三秒更新提示。
4. 搜尋幾個型號、打開產品明細，在後台查看該装置的查詢紀錄。
5. 提交缺少型號，在「型號審核」查看；只核准真實要納入的產品，下一次每日更新後查看「更新清單」。
6. 已載入料檔的手機離線重開，確認可以查詢。電腦停權手機，再讓手機回連並切回前端，
   應鎖定並清除本機受控料檔。最後可在後台重新開通自己的測試裝置。

每個瀏覽器／裝置需獨立申請；一般使用者不需要 Cloudflare 登入。
目前為功能分支測試版，尚待完成手機離線／停權等驗收；詳見 HANDOFF，不能直接視為正式上線驗收通過。

## 搜尋模式（v53）

在「更多選項 → 搜尋模式」選擇：

- **全部資訊（原有模式）**：比對型號、中文品名、價格、備註等一般產品資訊，不含@。
- **僅型號／中文品名**：只比對這兩個欄位，避免價格或備註造成不相關結果。

搜尋框上方會標示目前模式，點該按鈕會直接在兩種模式間切換；「更多選項」保留完整下拉選單。
兩種切換方式都會立即重新搜尋，不必重打關鍵字。
選擇保存在目前瀏覽器，重新整理、關閉頁面重開與離線使用都會沿用；不同瀏覽器各自設定。
清除網站資料後回到「全部資訊」。切換不影響價格顯示或@解鎖權限。

## 開發與发布

```powershell
npm ci
npm test
npm run build
# 僅在明確要發布程式時執行；需既有 Cloudflare 環境變數
npm run deploy
```

產品資料由另一 repo 的每日排程在 DB 同步、V36 快取及 selftest 成功後呼叫
`scripts/publish_data.py`。資料與程式分開發布，`git push` 不會執行上述部署命令。
舊 GitHub Pages 網站維持不變，新版不可用純靜態 server 取代後端。

## @ 解鎖（v54 待發布）

右上「模式標籤」點 5 次 → 左上「價」點 4 次 → 再點「模式標籤」3 次，
在密碼框輸入管理員設定的密碼。逐次間隔不超過三秒；點錯請稍等三秒重來。

管理員在後台「@密碼」設定／變更密碼（12～128 個字元，建議長密語）。
一般價格不受影響。解鎖後，同一瀏覽器重新整理、關閉重開、離線重開或每日更新料檔都會保留@權限；
「更多選項」可手動鎖回。重新認證／重新核准、停權或管理員變更@密碼時才會清除，之後需用新密碼解鎖。
瀏覽器不保存密碼或受保護資料明文，只保存不可匯出的解鎖金鑰。離線裝置無法即時收到停權或改密碼，請搭配裝置管理。

新版已移除 PDF 匯入、解析與預覽，只接受受控自動更新資料。
底層分離資料包已上線；管理員仍須親自進入後台設定@密碼，@才可解鎖。
日後單純 commit / push 仍不會自動部署。

## 本機開發驗證

```powershell
npm test
py -3.10 -m unittest discover -s tests -p test_publisher.py
npm run build
node tests/preview-server.mjs
```

Python 版本依本機安裝調整（先跑 `py -0p`）。
預覽程式只綁定 localhost，提供一筆假產品與記憶體資料庫；終端機會顯示隨機埠號網址。
它的 /admin 使用本機測試身分，僅用於前端流程驗證，不能部署或當成 Cloudflare Access 安全驗收。
結束程式後假資料消失；不得填入正式密碼。

本機瀏覽器已驗證@手勢、換密碼與停權清除；真手機飛航模式、離線重開仍待驗收。
